с множеством веток, персонализацией, эмоциональным сторителлингом и
сильным завлекающим CTA на съёмку.

1. Открой Claude / ChatGPT / Gemini
2. Сначала вставь **ВЕСЬ системный промпт** из [AI_FLOW_PROMPT.md](./AI_FLOW_PROMPT.md)
   (между маркерами `====BEGIN PROMPT====` и `====END PROMPT====`, плюс
   все v2/v3 секции с новыми блоками)
3. Потом в конце добавь:

```
### Задача: «Величественная воронка для Марины Заугольниковой»

Сделай флоу-воронку для бота фотографа Марины Заугольниковой (Москва).
Это не опросник. Это эмоциональный, тёплый, очень женственный сторителлинг,
который мягко ведёт человека от любопытства к желанию записаться на съёмку.

# ТРЕБОВАНИЯ К ОБЪЁМУ И СТРУКТУРЕ

- Минимум 50 узлов
- 4-5 разных сценарных веток (см. ниже)
- Каждый ответ юзера должен давать ПЕРСОНАЛЬНЫЙ резонанс (а не просто переход)
- Везде где можно — атмосферные тексты, метафоры, ~b:..~ ~i:..~ ~qx:..~ разметка
- Premium-эмодзи через ~emoji:5368324170671202286|✨~ — минимум 8 штук
- Кнопки с реальным style: "primary" (главные), "success" (зелёные — CTA),
  "danger" не используй, остальное — без style (default)
- ВЕЗДЕ обращение на «ты», на «вы» НИГДЕ
- typing-блок (1.2 сек) перед длинными сообщениями для драматической паузы

# DEEP-LINK ТРЕКИНГ

Если юзер пришёл по ссылке t.me/MarinaBot?start=ref_pin_42 — payload
будет в vars.ref. Если ref пустой — обычный сценарий.
В первом приветствии добавь блок branch:
  - if vars.ref не пустой → персональное приветствие с упоминанием
    "вижу, ты с Pinterest" / "рада что нашла меня через [соцсеть]"
  - else → обычное приветствие

# СЦЕНАРНЫЕ ВЕТКИ (ОБЯЗАТЕЛЬНО)

## Ветка А: «Хочу подобрать съёмку» (основная, ~60% узлов)
1. Приветствие → branch deeplink (см. выше)
2. Мягкий вопрос «что для тебя важно сейчас?» — кнопки-эмоции:
   - ~b:нежность~ → текст «нежность — это когда дыхание кадра становится твоим...»
   - ~b:сила~ → «когда смотришь в кадр и видишь себя — настоящую...»
   - ~b:лёгкость~ → «когда нет позы, есть жизнь...»
   - ~b:память~ → «когда хочется поймать этот момент навсегда...»
   - ~b:вдохновение~ → «когда нужны снимки которые будут двигать что-то внутри...»
3. После эмоции — typing → вопрос про повод (love-story / семейная / 
   беременность / индивидуальная / lookbook / контент для соцсетей)
4. По каждому поводу — своя цепочка из 2-3 узлов:
   - Короткий рассказ-сторителлинг от Марины ("я снимала пару, которая...")
   - Уточняющий вопрос (где / когда / с кем)
   - db_query outfits с фильтрами по поводу
5. show_outfits_voting с лайками
6. После лайков — typing 1.5 сек "собираю твою подборку..." → generate_pdf_voted
7. После PDF — РЕАЛЬНЫЙ CTA на съёмку (см. ниже)

## Ветка Б: «Хочу узнать о Марине» (~15% узлов)
Меню с 4 разделами (каждый — карточка + кнопка «← В меню»):
- «Как Марина снимает» — описание стиля и философии
- «Этапы съёмки» — те же 4 шага из брифа Марины (бриф → локация → образы → напоминание)
- «Что включено в пакеты» — кратко 5 пакетов
- «Отзывы и работы» — кнопка → t.me/MarinaPortfolio или сайт

## Ветка В: «Узнать пакеты и цены» (~15% узлов)
- Меню с 5 пакетами кнопками
- При клике на каждый — подробная карточка (текст из брифа Марины:
  Экспресс 15к, Лайт 25к, Комфорт 35к, Под ключ 115к, Репортаж от 8к)
- Внизу карточки — две кнопки: «Записаться на этот пакет» (style: success)
  и «← Назад к пакетам»

## Ветка Г: «Я по работе» (для брендов/редакций, ~5% узлов)
- Короткое сообщение «понимаю, тебе быстрее»
- Кнопки: «Связаться напрямую» (url t.me/mzaugolnikova),
  «Сайт» (url zaugolnikova.ru), «← Назад»

## Ветка Д: Финальный CTA «ЗАКАЗАТЬ СЪЁМКУ» (общий для веток А и В)

Это не одно сообщение. Это последовательность из 3-4 шагов:

1. send_message с заголовком ~b:Готова это снять~ и эмоциональным
   подводящим текстом ~qx:Каждая съёмка для меня — это история. Я
   снимаю не «фотографии», а тебя в моменте, когда ты живая.~

2. typing 1.5 сек

3. Меню пакетов кнопками (5 вариантов как в ветке В) — но с пометкой
   "✨ рекомендую под твой запрос" возле того, что ближе по vars.occasion
   (через switch по occasion → разные тексты)

4. Когда юзер выбирает пакет — финальный экран с:
   - Карточка пакета (полные условия)
   - Контакты: телефон, email, t.me/mzaugolnikova
   - Кнопка ~b:Написать Марине прямо сейчас~ (style: success, url t.me/mzaugolnikova)
   - ~qx: Условия брони: задаток 6000₽, не возвращается если студия подобрана.
     Перенос даты — до 2 раз. Стиль — естественный свет, лёгкая ретушь.~

# СПЕЦИАЛЬНЫЕ ЭЛЕМЕНТЫ

- В нескольких местах используй ask_poll вместо ask_question (для опросов
  «когда планируешь снимать?» с вариантами «в этом месяце» / «в течение 
  3 месяцев» / «когда-нибудь»)
- В одном месте используй send_quote с expandable: true для длинной цитаты
  Марины о её философии
- В одном месте — send_checklist с пунктами «что я даю»:
  ✅ Подбор студии · ✅ Лёгкая ретушь · ✅ Личная галерея · ✅ Сжатые сроки
- В одном месте — show_random_outfit для wow-эффекта «вот пример того,
  что я снимаю»
- В нескольких местах вставь delete_last_message count=2 перед длинными
  карточками — чтобы чат не превращался в простыню

# ТОН И СТИЛЬ ТЕКСТОВ

- Тёплый, поэтичный, женственный
- Метафоры света, дыхания, момента, истории
- Никаких канцеляризмов («осуществить», «производить съёмку»)
- Никаких CAPS-LOCK кроме слова "ЗАКАЗАТЬ СЪЁМКУ" в финальном CTA
- Каждое сообщение — короткое (1-3 абзаца), не простыни
- Между важными сообщениями — typing для ритма
```

## Что получишь на выходе

Флоу с примерно такой структурой:

```
trg_start (command)
  └─ welcome_branch (branch: vars.ref)
        ├─ welcome_with_ref (персональное)
        └─ welcome_default (обычное)
              └─ main_menu (5 кнопок-эмоций + ветки Б/В/Г)
                    ├─ feeling_softness → resonance_softness → typing → ask_occasion
                    ├─ feeling_strength → resonance_strength → typing → ask_occasion
                    ├─ feeling_lightness → resonance_lightness → typing → ask_occasion
                    ├─ feeling_memory → resonance_memory → typing → ask_occasion
                    └─ feeling_inspiration → resonance_inspiration → typing → ask_occasion

ask_occasion (switch по vars.occasion):
  ├─ love_story_intro → ask_couple_or_solo → query_outfits → voting → pdf → cta
  ├─ family_intro → ask_kids_age → query_outfits → voting → pdf → cta
  ├─ pregnancy_intro → ask_term → query_outfits → voting → pdf → cta
  ├─ individual_intro → ask_mood → query_outfits → voting → pdf → cta
  ├─ lookbook_intro → ask_count → query_outfits → voting → pdf → cta
  └─ content_intro → ask_niche → query_outfits → voting → pdf → cta

Все ветки сходятся в CTA:
  cta_intro → typing → cta_packages_menu (с пометкой ✨ рекомендую)
        ├─ pkg_express → contact_screen
        ├─ pkg_light → contact_screen
        ├─ pkg_comfort → contact_screen
        ├─ pkg_turnkey → contact_screen
        └─ pkg_reportage → contact_screen
              └─ contact_screen (карточка + кнопки) → end

Параллельно из main_menu:
  about_marina_menu (4 раздела: стиль, этапы, пакеты, отзывы)
  packages_menu (5 пакетов с обратной кнопкой)
  work_inquiry (контакты для брендов)
```

Это примерно 70-90 узлов в финале. **Реальная** воронка, а не опросник.
