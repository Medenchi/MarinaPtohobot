# 🎭 Промпт для генерации ВЕЛИЧЕСТВЕННОЙ воронки

Скопируй ВЕСЬ блок ниже (между маркерами), вставь в Claude / ChatGPT, получишь
готовый JSON. Он спроектирован так, чтобы Claude/GPT сгенерировал воронку с
максимальным конверсионным потенциалом.

---

```
====BEGIN GRAND PROMPT====

Ты — топовый CRO-копирайтер и архитектор Telegram-воронок. Я строю
бота для женского/контент-фотографа **Марины Заугольниковой** (Москва).

Твоя задача: спроектировать ВОРОНКУ-ШЕДЕВР, которая берёт холодного
человека из Pinterest и доводит до бронирования съёмки. Не опросник
ради опросника — а ТАМ ТО ИНТЕРАКТИВНОЕ ПУТЕШЕСТВИЕ, где каждый клик
повышает интерес, а финальный CTA воспринимается как ЕСТЕСТВЕННЫЙ ШАГ.

# Формат ответа

Только JSON-объект {name, description, graph: {nodes, edges: []}}.
БЕЗ ```json```, БЕЗ комментариев, БЕЗ преамбулы. С символа `{`.

# Архитектура воронки (минимум 50 узлов)

## АКТ 1 — Знакомство и интрига (5-7 узлов)
- /start триггер с поддержкой deep-link payload. Payload (если есть)
  уже сохранён в `{{vars.ref}}` — используй в персонализации:
  «Я вижу, ты пришла из Pinterest, доска "{{vars.ref}}"...»
- Welcome-сообщение с ПОЭТИКОЙ, не «здравствуйте, я бот». Опиши свет,
  движение, момент. Используй expandable blockquote ~qx:..~ для длинной
  истории, чтобы не пугать стеной текста. Эмодзи 🌿 ✨ 📸 — но ОЧЕНЬ
  УМЕРЕННО, 1-2 на сообщение.
- Первый выбор-зацепка: НЕ «давай начнём опросник», а вопрос-чувство
  («что тебя сейчас волнует больше всего в идее съёмки?»). 4-5 вариантов:
  - «✨ Хочу почувствовать себя красивой»
  - «🤍 Запомнить важный момент»
  - «📸 Контент для своих соцсетей»
  - «🤰 Беременность / семья / love-story»
  - «👀 Просто посмотреть»

## АКТ 2 — Персонализация и resonance (8-12 узлов)
- Switch по первому ответу → 4-5 индивидуальных текстов-«отражений»,
  которые показывают что Марина понимает её мотивацию. Это создаёт
  эмоциональный коннект.
- Дополнительные мягкие вопросы (необязательные, через ask_question с
  опцией «🤷 неважно»):
  - Повод (love-story/семейная/беременность/lookbook/контент/индивид.)
  - Стиль (минимализм/классика/old money/casual/романтика/бохо)
  - Цветовая палитра (бежевый/белый/чёрный/пастельный/...)
  - Сезон (или автоматически {{system.season}})
- На каждом 2-3 вопросе вставляй мини-социальное доказательство:
  «Чаще всего девушки в твоей нише выбирают X — попробуем?»

## АКТ 3 — Витрина с эмоциональным wow (10-15 узлов)
- `typing` + send_message «Сейчас подберу под тебя...» (создание ожидания)
- `db_query` к outfits с мягкими фильтрами через ilike (gender + occasion + style)
- `branch` на пустоту:
  - Если 0 → тёплое «у меня нет точного попадания, но я могу показать
    самое близкое» → query_nearest (без style фильтра)
- `show_outfits_voting` — карусель с 👍/💔. Перед ней — ОБЯЗАТЕЛЬНО
  intro-сообщение «Отмечай только то, что хочется надеть прямо сейчас»
- `generate_pdf_voted` — соберёт PDF с разделами «Понравилось» / «Может подойти»

## АКТ 4 — Социальное доказательство (5-7 узлов)
- После показа подборки — БЛОК ОТЗЫВОВ: ~qx:..~ с цитатой клиентки
  («Это была самая комфортная съёмка в моей жизни. Я думала, буду стесняться,
  но Марина создала такую атмосферу...» — придумай 2-3 правдоподобных
  отзыва на разные типы съёмок).
- Краткое about Марины: 1 предложение про подход + 1 факт-крючок
  («Снимаю 5+ лет, в портфолио более 800 девушек, работаю до результата»).

## АКТ 5 — Снятие возражений (8-10 узлов)
- Меню с типичными страхами: send_message с кнопками
  «😅 А если я не фотогенична?», «💸 Дорого ли это?», «🕐 Сколько по времени?»,
  «👗 Что надеть?», «📸 Можно с детьми?». Каждая кнопка ведёт на узел с
  конкретным мягким ответом (~qx:..~ для длинных + кнопка «← Назад»).
- В каждом ответе — мягкое подведение к CTA в конце.

## АКТ 6 — Главный CTA: ЗАКАЗ СЪЁМКИ (6-8 узлов)
- send_heading с уровнем 1: «📸 Когда планируешь?»
- ask_question с вариантами:
  - «🔥 Срочно — в ближайшие 2 недели»
  - «🌿 В этом месяце»
  - «🌸 Через 1-2 месяца»
  - «🤔 Просто исследую»
- switch по выбору:
  - «Срочно» → бронь сразу, акцент на доступности и быстром старте
  - «Этом месяце» → подборка ближайших слотов, скидка за раннее бронирование
  - «Через 1-2» → подписка на даты, мягкий уход
  - «Исследую» → отправить PDF на email + предложение подписаться на канал
- Финальный send_message со ВСЕМИ 5 пакетами Марины ОФОРМЛЕННЫМИ красиво:
  Экспресс 15к / Лайт 25к / Комфорт 35к / Под ключ 115к / Репортаж от 8к/час
  Используй чёткие визуальные блоки: эмодзи ✨🌿💫👑🎥, ~b:..~ для названий,
  обычный текст для деталей.
  Кнопки: 
  - «💬 Написать Марине» style:success url:https://t.me/mzaugolnikova
  - «🌐 Сайт» style:default url:https://zaugolnikova.ru/
  - «🔄 Пройти заново» style:default next:welcome

## АКТ 7 — Дополнительные ветки (3-5 узлов)
- На welcome — кнопка «💼 Я по работе» → отдельная ветка с быстрыми
  контактами (без воронки)
- text_match триггер на «цена/стоимость/прайс» → сразу пакеты
- text_match триггер на «отзывы» → блок социальных доказательств
- text_match триггер на «портфолио» → ссылка на zaugolnikova.ru

# Доступные блоки

## Триггеры:
- command (params: command, keep_vars?) → next
- text_match (params: pattern, mode: exact|contains|starts_with) → next

## Сообщения:
- send_message (text, buttons?, parse_mode? - всегда HTML)
- send_heading (text, icon?, level: 1|2|3)
- send_quote (text, author?, expandable?)
- send_checklist (title?, items: [..])
- send_numbered_list (title?, items: [..])
- typing (seconds)
- delay (seconds)

## Ввод:
- ask_question (text, variable!, options?: [{text, value}], inline?: true) → next
  ВАЖНО: каждое варианты должны быть СЕМАНТИЧЕСКИ ВАЛИДНЫМИ для последующих
  db_query — используй РОВНО эти значения категорий:
    gender: «женское», «мужское»
    occasions: «love-story», «семейная съёмка», «беременность», 
               «индивидуальная», «lookbook», «контент для соцсетей», 
               «репортаж», «прогулка»
    styles: «casual», «smart casual», «классика», «романтика», 
            «минимализм», «old money», «бохо»
    colors: «бежевый», «белый», «чёрный», «серый», «молочный», 
            «оливковый», «пастельный», «бордовый»

## Логика:
- branch (variable, op: eq|neq|contains|not_empty|empty|gt|lt|in, value, true_next, false_next)
  ❗ branch НЕ имеет верхнего next, только true_next/false_next в params
- switch (variable, cases: {«value»: «node_id»}, default)
- set_variable (name, value)
- goto (params: {next: «node_id»})
- end (params: {}, next: null)

## Данные:
- db_query (table: «outfits», select, filters: [{column, op, value}], 
            order_by?, limit?, save_to)
  Для тегов через запятую — op: «ilike», value: «%{{vars.x}}%»
- db_insert (table: «bookings», fields: {col: val})

## Спец:
- show_outfits_voting (items_var: «matched_outfits», limit?, 
                       liked_var: «liked_ids», disliked_var: «disliked_ids», 
                       done_text, done_button) → next
- generate_pdf_voted (items_var, liked_var, filename, caption, send_now?: true, save_to)
- delete_last_message (count?: 1)
- handoff_to_admin (text)

# Лёгкая разметка текстов

В любом строковом param используй:
- ~b:текст~        → <b>текст</b>
- ~i:текст~        → <i>текст</i>
- ~u:..~  ~s:..~  ~code:..~  ~spoiler:..~
- ~q:цитата~       → blockquote
- ~qx:длинная цитата~ → expandable blockquote (раскрывается по клику)
- ~link:https://x|текст~ → <a href="x">текст</a>
- ~emoji:ID|✨~ → <tg-emoji emoji-id="ID">✨</tg-emoji> 
  (premium-эмодзи; видны всем при условии что у владельца бота TG Premium)
  В тексте кнопки тоже можно: ~emoji:ID|✨~ — движок автоматически
  вытащит ID в icon_custom_emoji_id и оставит fallback в text. 
  ⚠ Чтобы premium-эмодзи РЕАЛЬНО показывался в кнопке всем юзерам — 
  у владельца бота должен быть Telegram Premium. Без Premium TG покажет
  только обычный fallback-эмодзи.

# Цвета кнопок (Bot API 9.4+, 4 валидных значения)

В каждой кнопке можно указать style:
- default (или не указывать) → обычная серая
- primary → синий акцент (главное действие)
- success → зелёный (подтвердить/успех)
- danger → красный (отменить/опасно)

⚠ warning и secondary НЕ РАБОТАЮТ — Telegram вернёт invalid button style.
Используй только эти 4. Цвета — мощный конверсионный приём, не злоупотребляй
(не более 1 primary на сообщение, иначе теряет смысл).

# Deep-link реклама

Бот автоматически фиксирует payload из /start в {{vars.ref}} и в bot_events.
Ты можешь приветствовать по-разному:
  Если payload «pin_42» — «Я вижу, ты с Pinterest, доски "Эстетика осени"...»
  Если payload «inst_story» — «Привет! Ты пришла из stories...»
  Если payload пуст — обычное приветствие.

Реализуй через branch на {{vars.ref}} с op:«not_empty» в самом начале, 
если хочешь branding-аналитику. Или просто упомяни {{vars.ref}} в welcome 
один раз — этого хватит для wow-эффекта.

# ЖЁСТКИЕ ПРАВИЛА (нарушать НЕЛЬЗЯ)

1. id уникальны в графе, snake_case
2. Каждый next ссылается на существующий id или null  
3. Каждый ask_question имеет params.variable
4. Минимум 1 триггер command («start»)
5. ВСЕ блоки достижимы от триггера (через next/кнопки/branch/switch)
6. url в кнопках — только https://, http://, tg://, t.me/
7. buttons — это [[btn,btn],[btn]] МАССИВ РЯДОВ
8. branch без верхнего next — только true_next/false_next в params
9. parse_mode не указывай — движок сам поставит HTML
10. Тексты на ТЫ. Поэтика без приторности. Длинные тексты в ~qx:..~
11. JSON синтаксически валиден
12. Не используй tel: и mailto: — TG их режет

# Стиль текстов

- Не «здравствуйте, я бот». Говори от лица Марины («Я Марина...»)
- Не «выберите вариант». «Выбери то, что отзывается»
- Не «давайте начнём». «Готова посмотреть, что у меня для тебя есть?»
- Не «спасибо за заявку». «Жду тебя на съёмке — это будет красиво»
- Эмодзи: 1-2 на сообщение, на конкретный акцент. Не каждый абзац начинать
- Длинные блоки — обязательно ~qx:..~ чтобы не было стены текста
- В CTA-кнопках обязательно эмодзи в начале: «✨ Хочу записаться», 
  «💬 Написать Марине» — это +30% к CTR
```

## Как использовать

1. Скопируй ВСЁ между маркерами `====BEGIN GRAND PROMPT====` и `====END GRAND PROMPT====`
2. Вставь в Claude / ChatGPT / любую LLM
3. В строке `### Задача` где `{{ВПИШИ_СВОЁ}}` — впиши конкретное название, например:
   - `«Осенняя подборка»`
   - `«Подбор образов для семейной съёмки»`
   - `«Lookbook для брендов»`
4. Получишь чистый JSON. Сохрани как `мой-флоу.json`.
5. Открой `/admin` на Vercel-фронте → Импорт → выбери файл.
6. AI-валидатор покажет `❗ 0 ⚠ 0 💡 0` если всё ок.
7. Опубликуй.

## Если AI-валидатор показал ошибки

Скопируй текст ошибок (например, `dangling_next в node X`) обратно в чат с LLM, скажи «исправь эти ошибки и пришли весь JSON заново». Цикл до зелёного.

## Использование deep-link

После публикации флоу — давай ссылки с метками:

```
https://t.me/MarinaZaugolnikovaBot?start=pin_autumn
https://t.me/MarinaZaugolnikovaBot?start=pin_winter  
https://t.me/MarinaZaugolnikovaBot?start=inst_reel_42
https://t.me/MarinaZaugolnikovaBot?start=story_blog
```

Где `pin_autumn` / `inst_reel_42` — твоя метка. **На каждый пост в Pinterest свою**.

Затем в **`/mama/stats`** → раздел **«🔗 Источники переходов»** увидишь:
- Сколько раз перешли по каждой метке
- Сколько уникальных юзеров с метки
- Когда последний раз заходили

Это бесплатная атрибуция трафика без UTM-меток и Google Analytics.
