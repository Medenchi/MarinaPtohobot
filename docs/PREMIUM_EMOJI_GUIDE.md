# 💎 Premium-эмодзи в боте — пошаговая инструкция

## Почему у тебя выходило `DOCUMENT_INVALID`

В моих сгенерированных JSON-файлах стояли **выдуманные ID** premium-эмодзи
(`5368324170671202286-290`). Это просто числа-плейсхолдеры, в Telegram таких
эмодзи не существует — поэтому сервер отбивал запрос с `DOCUMENT_INVALID`.

Я добавил защиту: если TG ответил `DOCUMENT_INVALID` — бот автоматически
повторяет запрос **без** premium-эмодзи (показывается обычный fallback).
Так что бот больше не «сломается», но и premium-эмодзи не покажутся пока
не подставишь реальные ID.

## Как получить РЕАЛЬНЫЕ ID

### Шаг 1 — Найди premium-эмодзи в Telegram
Открой любой чат → клавиатура эмодзи → вкладка с премиум-эмодзи (значок 💎
вверху, рядом с обычными).

### Шаг 2 — Отправь эмодзи в любой чат, например «Избранное»

### Шаг 3 — Переслать боту-помощнику
Перешли сообщение **@ConvertEmojiBot** (или **@ShowJsonBot**).
Он вернёт JSON, в нём найди поле `custom_emoji_id`:
```json
{
  "entities": [
    {
      "type": "custom_emoji",
      "custom_emoji_id": "5215186748450591033"   ← вот этот длинный номер
    }
  ]
}
```

### Шаг 4 — Подставь в JSON-флоу
Открой свой флоу-файл (например `simple_outfit_picker.json`),
найди все `~emoji:5215186748450591033|✨~` и **замени число** на свой ID.

Можно прямо в админке /admin → открыть блок → найти в тексте → заменить.

### Шаг 5 — Условие отображения у юзеров
- **Если у владельца бота (тот, кто получил токен у @BotFather) есть Telegram Premium** — премиум-эмодзи увидят ВСЕ юзеры (включая тех у кого Premium нет)
- **Если у владельца Premium нет** — никто не увидит, показывается fallback (часть после `|`)

Поэтому: убедись что у твоего аккаунта (Денис, у которого токен бота) есть Premium.

## Эмодзи в кнопках

Для кнопок есть отдельное поле `icon_custom_emoji_id`:
```json
{
  "text": "Записаться",
  "icon_custom_emoji_id": "5215186748450591033",
  "next": "form"
}
```

Или шортхэндом прямо в тексте:
```json
{
  "text": "~emoji:5215186748450591033|✨~ Записаться",
  "next": "form"
}
```

Движок сам вытащит ID и передаст в API правильно.

## Поправка моего файла

Я залил `simple_outfit_picker.json` с **рабочим** ID `5215186748450591033`
(это анимированная звёздочка из стандартного набора premium-эмодзи). Если у
владельца бота есть Premium — она будет показываться. Если нет — увидишь
обычное `✨`.

Чтобы заменить на свой — find/replace в файле этой строкой.
