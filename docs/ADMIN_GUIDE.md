# 🛠 Руководство админа (Денис)

Это инструкция для админской панели и конструктора бота.
Открывается на **https://marinazau.denchy.cyou/admin**.

См. также:
- [`FLOW_FORMAT.md`](./FLOW_FORMAT.md) — полная спецификация JSON-графа флоу
- [`MAMA_GUIDE.md`](./MAMA_GUIDE.md) — что видит Марина
- [`flows/marina_preshoot_brief.json`](./flows/marina_preshoot_brief.json) — готовый шаблон опросника

---

## Вход

`/admin/login` → пароль (тот, что задан в `ADMIN_PASSWORD` Supabase Edge
Function `admin-login`). Сессия 24 часа.

---

## Главная `/admin` — список флоу

* **+ Новый флоу** — пустой граф
* **Стартовый шаблон** — мини-граф «привет → имя → тип съёмки → спасибо»
* **Импорт** — загрузить JSON (например, `marina_preshoot_brief.json`)
* **Экспорт** — скачать JSON конкретного флоу
* **Дубликат** — копия с (copy) в названии
* **Категории** — управление справочниками
* **Выйти**

⭐ напротив имени = флоу опубликован, бот гоняет именно его.

## Конструктор `/admin/flows/<id>`

### Шапка

| Кнопка | Что делает |
|---|---|
| `❗ N ⚠ N 💡 N` | счётчики AI-валидатора (детали — внутри списка блоков) |
| Список / Карта | переключатель режима — текстовый список ИЛИ интерактивный граф с верёвочками |
| 🧠 **Шаблоны** | боковая панель с готовыми блоками (поводы / образы / курсы / пакеты Марины / контакты) |
| 📖 **Переменные** | боковая панель со всеми `user.*` и `vars.*` этого флоу |
| Сохранить / Превью | автосейв через 800 мс после правки + явная кнопка; «Превью» шлёт текущий черновик тебе в Telegram |
| Опубликовать / Снять | публикация (бот сразу переключается) |

### Режим «Карта»

* Тянешь блоки мышкой — позиции сохраняются в графе.
* Чтобы соединить — тянешь от **синей точки справа** блока к **левой точке** другого блока.
* Удалить связь `next` — правый клик по серой/синей верёвочке.
* Удалить блок — × в правом верхнем углу узла.
* На узле появляется **красный/жёлтый кружок**, если на нём есть ошибка/ворнинг валидатора.

### Левая колонка — типы блоков

7 групп (Триггеры, Сообщения, Вопросы, Логика, Данные, Спец). Полный список
с параметрами — в [`FLOW_FORMAT.md`](./FLOW_FORMAT.md). Клик добавляет узел.

### Правая колонка — инспектор

Когда выбран блок, тут поля для редактирования его `params`. Самые частые:
- `text` (с поддержкой `{{vars.x}}` и `{{user.first_name}}`)
- `variable` (для `ask_question`)
- `buttons` — редактор inline-кнопок
- `next` — выпадашка по всем узлам флоу

### 📖 Панель «Переменные»

Скан графа: какие переменные где создаются и где используются. Клик по
токену копирует `{{vars.имя}}` в буфер — удобно вставлять в тексты.

Если переменная **используется**, но **нигде не создана** — она
подсветится с пометкой «висячая». Это частый баг: написал
`{{vars.color}}` в сообщении, а блок-вопроса с `variable: color` нет.

### 🧠 Панель «Шаблоны»

12 готовых наборов узлов под флоу Марины — клик и они вставляются
**справа** от твоего графа. Останется только протянуть стрелочку от
твоего блока к первому новому.

- **Поводы** — готовый ask_question с типами съёмок
- **Образы** — db_query по `occasions ilike '%{{vars.occasion}}%'` + альбом + PDF
- **Курсы** — список published курсов
- **Пакеты Марины** — Экспресс 15к / Лайт 25к / Комфорт 35к / Под ключ 115к / Репортаж от 8к + «Меню всех пакетов» одним блоком
- **Контакты и условия** — карточка контактов / этапы подготовки / важные условия

## Категории `/admin/categories`

Справочник тэгов, который Марина видит в выпадашках при редактировании
образа. Семь разделов:

| Раздел | Что значит |
|---|---|
| **Цвета** | бежевый, белый, чёрный, оливковый… |
| **Стили** | casual, smart casual, классика, old money… |
| **Сезоны** | весна, лето, осень, зима, межсезонье |
| **Поводы** | love-story, семейная съёмка, беременность, lookbook… |
| **Фигура** | песочные часы, груша, plus size… |
| **Бюджет** | до 5к, 5–15к, 15–30к, 30–60к, 60к+ |
| **Тип съёмки** | студия, улица, дома у клиента, природа, золотой час… |

В каждой карточке:
- Список текущих значений (× удаляет)
- Поле «новое значение» → `+ Добавить`

⚠ Удаление значения **не трогает** уже сохранённые образы — там оно
останется как обычный текст в выпадашке, пока Марина сама не уберёт.

## Мини-конструктор в боте (`/builder`)

Если совсем нет под рукой ноутбука — пиши боту `/builder` (доступно
только владельцу, по `BOT_OWNER_TELEGRAM_ID`):
- Список флоу
- Открыть → видишь карту блоков + AI-проверку
- ➕ Сообщение / ❓ Вопрос — быстро добавить простой узел
- 🧠 AI-проверка → подробный отчёт
- ⭐ Опубликовать / ⏸ Снять
- 👁 Превью — пришлёт тебе текущий черновик в Telegram

## AI-валидатор

Что ловит:

| Код | Уровень | Что значит |
|---|---|---|
| `no_trigger` | ❗ | нет ни одного `command`/`text_match` |
| `duplicate_id` | ❗ | повторяющийся id |
| `dangling_next` | ❗ | `next` указывает в никуда |
| `no_variable` | ❗ | `ask_question` без `variable` |
| `dangling_button` | ❗ | кнопка ссылается на несуществующий узел |
| `empty_text` | ⚠ | `send_message` с пустым текстом |
| `empty_question` | ⚠ | `ask_question` без текста |
| `no_buttons` | ⚠ | блок `buttons` без кнопок |
| `self_loop` | ⚠ | узел ссылается сам на себя |
| `unreachable` | 💡 | блок не достижим ни от одного триггера |

Гоняется автоматически после каждой правки + по кнопке «AI-проверка» в
`/builder`.

## База: основные таблицы

| Таблица | Что |
|---|---|
| `bot_flows` | флоу (graph jsonb), `is_published` управляет, какой гоняет бот |
| `bot_sessions` | состояние диалога каждого пользователя |
| `bot_users` | список тех, кто хоть раз писал |
| `bot_events` | аналитика (для `/mama/stats`) |
| `bot_preview_requests` | очередь превью из конструктора |
| `outfits` | образы (теги — через запятую в text-колонках) |
| `outfit_images` | фото образов (storage_path в bucket `outfit-images`) |
| `outfit_categories` | справочник тегов (управляется в `/admin/categories`) |
| `courses` | курсы |
| `bookings` | заявки с брифа |

## Миграции

В `supabase/migrations/` лежат:

```
0001_init.sql                     — основные таблицы (outfits, courses, bookings, bot_users)
0002_storage.sql                  — buckets (outfit-images, course-files, outfit-pdfs)
0004_seed.sql                     — демо-образы
0005_constructor.sql              — bot_flows, bot_sessions, bot_events
0006_supabase_only.sql            — RLS-политики для frontend через supabase-js
0007_session_flow_guard.sql       — защита FK при удалении flow_id
0008_outfit_categories.sql        — справочник тегов
```

Выполнять в SQL Editor **по порядку**, по одному разу.

## Деплой

* **Фронт** — авто, по push в `main` (GitHub Actions `frontend.yml`) → GitHub
  Pages → `marinazau.denchy.cyou`.
* **Бот** — на Wispbyte, делает `git pull && python backend/app/bot/main.py`
  при старте контейнера. Достаточно «Restart» после нового коммита.
* **Edge Function `admin-login`** — деплоится руками через
  `supabase functions deploy admin-login --no-verify-jwt`, отдельно.
